7-Stage DistilBERT Thematic Processing Pipeline
How raw text is transformed into outcome probabilities and themes
1. Standardized Sequence Construction: Joins Headline | Position | Company | About | Skills into a unified semantic sequence.
2. WordPiece Subword Tokenization: Maps text into 30,522-vocab subword IDs prepended with [CLS] (101) and appended with [SEP] (102).
3. Dual Embedding Lookup: Combines Token Embeddings + Positional Embeddings into a $(1 \times L \times 768)$ dense tensor.
4. 6-Layer Multi-Head Self-Attention: 12 attention heads ($d_k = 64$) link intent modifiers (e.g., "seeking", "aspiring") directly to role nouns.
5. [CLS] Pooled Representation: Extracts the 768-dimensional contextual summary vector at index 0.
6. Linear Logits & Softmax: Projects $\mathbb{R}^{768} \rightarrow \mathbb{R}^3$ logits and computes Softmax probabilities $P(y=k|\mathbf{x})$.
7. Thematic Coding & TF-IDF Clustering: Combines codebook phrase weights, DistilBERT priors, and K-Means clustering.
